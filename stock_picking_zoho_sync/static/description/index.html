Stock Picking Zoho Sync

Synchronize incoming stock receipts with Zoho

This module synchronizes validated incoming stock receipts (Receipts) with Zoho through an external HTTP endpoint.

  • Receipts are flagged as pending synchronization as soon as they are validated, without delaying the transaction.
  • A scheduled action, running every 10 minutes, sends all pending receipts to Zoho.
  • The unit price sent for each line comes from the linked purchase order line, with the product's cost price used as a fallback for manual receipts without a purchase order.
  • Failed sends are retried automatically on the next run.
