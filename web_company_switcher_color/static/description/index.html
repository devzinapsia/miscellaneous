Color de empresa activa

See at a glance which companies are active

Paints the company switcher with the color defined on each company: the systray button shows the active company's color (or one stripe per selected company), and every row of the dropdown shows a solid block of its company's color.

Dropdown: one color block per company, selected or not.

One company selected: its name on its own color.

Key Features

  • Colored systray button: the active company's name on its own color.
  • Several companies: equal, hard-edged stripes, current company first; a rainbow when more than five are selected.
  • Color column in the dropdown: a full-height color block per company, selected or not, also in the mobile burger menu.
  • Readable text: black or white text picked from the WCAG relative luminance of the background.
  • No configuration: uses the standard company color field.

Developed by Zinapsia for Odoo 19.
